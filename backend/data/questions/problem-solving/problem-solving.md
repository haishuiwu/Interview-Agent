## 1. 拆解时间不足

**训练任务：** 你最近总是来不及完成限时练习。请把“时间不够”拆成至少三个可能原因，并说明你会先验证哪一个。

**参考思路：** 可从知识不熟、审题慢、步骤安排不合理、卡题时间过长或注意力分散等方面拆解。优先验证应结合影响程度和可获取证据，例如记录每道题耗时与错误类型。

**难度：** easy。**类型：** practice。**训练能力：** 问题解决、问题拆解、验证意识。

## 2. 排查实验失败

**训练任务：** 小组实验连续两次失败，材料只够再做两次。请提出排查顺序、每次实验只改变的变量，以及判断方案有效的标准。

**参考思路：** 先根据记录定位最可能且影响最大的原因，按优先级排查；每次只改变一个关键变量并保持其他条件一致；提前定义成功指标和记录方式。

**难度：** medium。**类型：** scenario。**训练能力：** 问题解决、方案设计、变量控制。

## 3. 设计低成本改进方案

**训练任务：** 学校希望减少午间食物浪费，但不能增加大量管理成本。请界定问题、提出两个方案、比较取舍，并设计一周内可完成的小规模验证。

**参考思路：** 明确浪费量、原因、对象和成本约束；方案可包括小份选择、需求预报或反馈提示。比较效果、实施成本和副作用，再选择少量班级试行并记录人均浪费、参与率和排队时间。

**难度：** hard。**类型：** scenario。**训练能力：** 问题解决、多方案比较、行动验证。
